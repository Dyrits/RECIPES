# Recipes

A basic recipe website built with HTML, as a The Odin Project foundations project.

## About The Project

From the original README: this repository holds the "Project: Recipes" of [The Odin Project](https://www.theodinproject.com/) Foundations course (HTML Foundations). The site consists of a main index page linking to a few recipe pages. The original assignment text is preserved in [ASSIGNMENT.md](ASSIGNMENT.md).

## Built With

- HTML / CSS

## Getting Started

Open `index.html` in a browser.
